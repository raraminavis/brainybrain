# Jupyter Notebooks

This directory contains Jupyter notebooks for interactive data analysis and visualization.

## Organization

- Name notebooks descriptively: `01_data_exploration.ipynb`, `02_spike_analysis.ipynb`
- Use numbered prefixes for analysis workflow steps
- Document your analysis with markdown cells

## Getting Started

Launch Jupyter from the repository root:

```bash
jupyter notebook
```

Then navigate to the `notebooks/` directory.

## Best Practices

- Keep notebooks focused on specific analysis tasks
- Use relative paths to access data and modules
- Export important functions to the `python/` or `matlab/` directories for reuse
- Save figures to appropriate results directories
