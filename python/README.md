# Python Analysis Modules

This directory contains Python modules and scripts for neural data analysis.

## Structure

- `utils/`: Utility functions for data loading, preprocessing, and visualization
- `analysis/`: Main analysis scripts
- `examples/`: Example scripts demonstrating common analysis patterns

## Getting Started

Add this directory to your Python path to use the modules:

```python
import sys
sys.path.append('/path/to/brainybrain/python')
```

Or install in development mode:

```bash
pip install -e .
```

## Common Workflows

See the `examples/` directory for common analysis patterns following the Neural Data Science book.
