# Matlab Analysis Scripts

This directory contains Matlab functions and scripts for neural data analysis.

## Structure

- `utils/`: Utility functions for data loading, preprocessing, and visualization
- `analysis/`: Main analysis scripts
- `examples/`: Example scripts demonstrating common analysis patterns

## Getting Started

Add this directory to your Matlab path:

```matlab
addpath(genpath('/path/to/brainybrain/matlab'));
```

Or use the provided startup script:

```matlab
run('setup_matlab_path.m');
```

## Common Workflows

See the `examples/` directory for common analysis patterns following the Neural Data Science book.
